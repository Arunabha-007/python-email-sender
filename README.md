# Python Email Sender

This project is a simple Python email automation tool that sends emails to multiple recipients one-by-one using SMTP.

## Features

* Send bulk emails automatically
* Gmail SMTP support
* Secure login using App Passwords
* Easy recipient list management
* Delay support to avoid spam detection

## Technologies Used

* Python
* smtplib
* email.mime

## Usage

1. Install Python
2. Add your Gmail and App Password
3. Add recipient email addresses
4. Run:

```bash
python send_mail.py
```

## Warning

Do not upload real passwords or sensitive credentials to GitHub.
